**Поисковик по актуальному списку заблокированых доменов в РФ!**

Discord-бот Запретян - это приложение для серверов и пользовательских профилей, позволяющее совершать поиск по заблокированым доменам и IP адресам в реестре Роскомнадзора! Также бот имеет возможность показыать IP адрес ресурсов по доменному имени и узнавать географическое расположение сайта или IP адреса!

Запретян также отсылает новые блокировки по мере их появления [на нашем Discord-Сервере](https://discord.gg/e2HcXrQ)

## Команды
 - К некоторым командам доступен аргумент `publicreply: true / false`. Если `True`, то ответ от бота увидят все в чате, а не только вы.
 - `/bancheck` - Проверяет по базе данных добавлен ли домен или IP в реестр блокировок Роскомнадзора и принадлежит ли ресурс провайдеру, работу которого строго ограничивают в РФ. Аргументы: `type`,`string`,`publicreply`
   - `type` - `Домен` - если вы хотите проверить наличие сайта в реестре блокировок (прим. instagram.com). `IP адрес` - если вы хотите проверить наличие IP в базах ограничений РКН.
   - `string` - домен или IP адрес, который вы хотите проверить.
- `/total` - Узнать сколько было заблокировано адресов и доменов за сегодня и всего. Аргументы: `publicreply`
> [!IMPORTANT]
> Ресурсы могут быть заблокированы точечно, без тупого добавления их в списки ТСПУ. По этой причине вы не найдёте `youtube.com` в базе данных заблокированых адресов. Бот отдаст ответ что сайт возможно заблокирован.
>
>Также в список таких сайтов попадают сайты, защищённые Cloudflare. Такие запросы тоже будут получать ответ о возможной блокировке. Наш `lunarcreators.ru` расположен в РФ и не заблокирован, но защищён облаком Cloudflare, поэтому он не откроется в РФ без средств обхода блокировок.

- `/dig` - Узнать адрес интернет ресурса из домена (`A`, `AAAA` DNS записи) или проверить принадлежность IP адреса к интернет ресурсу (`PTR` DNS запись). Возможен запрос и других DNS записей через публичный DNS резолвер. Аргументы: `type`,`string`,`publicreply`
  - `type` тип DNS записи (как в dig или nslookup)
    - `A (IPv4)` - узнать IPv4 адрес сайта
    - `AAAA (IPv6)` - узнать IPv6 адрес сайта
    - [`CNAME`](https://knowledge.workspace.google.com/admin/domains/about-cname-records?hl=ru) - узнать синонимом какого домена является запрашиваемое доменное имя
    - [`MX`](https://ru.wikipedia.org/wiki/%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D1%8C_MX) - прочитать почтовые записи домена
    - [`TXT`](https://knowledge.workspace.google.com/admin/domains/about-txt-records?hl=ru) - Прочитать текстовые записи домена
    - `NS` - Прочитать сервера доменных имён, закреплённых за доменом (запись указывает, какой сервер содержит фактические записи DNS)
    - [`PTR`](https://ru.wikipedia.org/wiki/%D0%9E%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D1%8B%D0%B9_%D0%BF%D1%80%D0%BE%D1%81%D0%BC%D0%BE%D1%82%D1%80_DNS) - **УКАЗЫВАТЬ IPv4 АДРЕС!** Показывает связь IPv4 адреса с доменом, если такая имеется (Обратный просмотр DNS)
  - `string` - домен (IP адрес в случае `PTR`), информацию о котором вы хотите получить
> [!IMPORTANT]
> Результаты запроса получаются из публичного DNS-резолвера Google
> 
> Конкретные IP адреса крупных сервисов за CDN (прим. YouTube) меняются в зависимости от географического положения. Бот отдаёт результаты относительно местоположения сервера
- `/who` - Узнать приблизительное расположение сайта или IP адреса и его провайдера из бесплатных баз данных [MaxMind](https://www.maxmind.com). Аргументы: `type`,`string`,`publicreply`
   - `type` - `Домен` - Из указанного домена будет получен IP и по нему будут получены данные о расположении и провайдере. `IP адрес` - Узнать данные по указанному IP адресу.
   - `string` - домен или IP адрес, информацию о котором вы хотите получить. 
 > [!WARNING]
 > Команда `/who` ограничена в использовании до 10 запросов в час на каждый аккаунт Discord для избежания злоупотребления базами данных
- `/ping` - Проверка отклика бота
- `/invite` - Пригласить бота на свой сервер или установить к себе на аккаунт для использования в любом месте
- `/about` - Подробная информация о приложении
